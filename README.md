# Nuhunie (mockup)

구매대행(jastip) 주문·결제 확인 사이트 목업. 서버 없이 브라우저에서만 동작하며 데이터는 그 브라우저의 localStorage에 저장된다.

## 화면

- 서비스 → 월별 배치 → 배치 리캡
- 주문 조회 (주문번호·아이디)
- 결제 확인 → 영수증
- 관리자: 사용 안내, 배치, 주문 입력(자동 분류), 결제 확인, 가격 계산기, 주문 CSV 내려받기

언어: 인도네시아어 · 영어 · 한국어

## 구조

| 층 | 파일 | 역할 |
|---|---|---|
| 1 | `js/data.js` | 데이터 모델, 상호(`GO.BRAND`), 예시 데이터 |
| 2 | `js/logic.js` | 가격 계산, 집계, 조회, 자동 분류, CSV |
| 3 | `js/store.js` | 읽고 쓰는 통로 (목업은 localStorage) |
| 4 | `js/ui.js` | 화면과 이벤트 |
| – | `js/i18n-en.js` | 영어 문구 |
| – | `css/app.css` | 스타일과 배색 테마 |

## 검사

- 계산 로직 단위 테스트: `node --test tests/logic.test.js`
- 고객·운영자 여정 자동 실행: 사이트를 연 브라우저 콘솔에서 `await import('./tests/e2e.js'); await runE2E()` (저장된 데이터가 예시로 초기화된다)

## 목업의 한계

관리자 로그인 없음, 결제사 미연결(QR·계좌는 예시), 증빙 이미지는 저장하지 않음, 자동 분류는 규칙 기반(AI 미연결).
